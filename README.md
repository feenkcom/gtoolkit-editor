# gtoolkit-editor
Text Editor for Glamorous Toolkit

## Installation

```st
Metacello new
	repository: 'github://feenkcom/gtoolkit-editor:main/src';
	baseline: 'GToolkitEditor';
	load
```

## Load Lepiter

After installing with Metacello, you will be able to execute

```
#BaselineOfGToolkitEditor asClass loadLepiter
```
